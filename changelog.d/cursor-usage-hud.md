### Added

- The bottom of the agent list shows your Cursor plan as a game HUD: HP is the total left, AUTO is
  what is left for Cursor's own models, and API is what is left for other models, with the time to
  the reset. The reactor shows the CPU and memory of the server to its owners and admins. Hover a
  part to see what it counts. It shows on the desktop app, with a joined server, and in the web
  client. With a joined server, HP shows the plan total only when the server is also on this
  version; an older server does not send the total, so HP shows the pool that runs out first.
